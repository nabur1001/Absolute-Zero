Read [project compatibility](../../UNITY_COMPATIBILITY.md) before using the examples. Reuse current bridges/presenters and lobby flow. UI Toolkit navigation examples do not authorize replacing production uGUI or adding another state owner.

## How to use

Identify the existing code/assets and relevant design/plan first. Reuse available specialist skills (ui, ui-ugui, ui-uitk) for their concrete operations; this topic supplies complementary reference depth. No package installation, scene change, gameplay expansion, or architectural migration follows merely from loading this skill.

Read only the relevant sections of [the topic guide](reference-guide.md), then the detailed reference needed for the task. Verify selected example signatures against the installed Unity/package version before adapting code. Preserve cancellation, authority and ownership. Report what was actually compiled or exercised.
