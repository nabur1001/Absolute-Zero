## 3. Multi-Player 전투 해결 (신규 5건)

> 3~4명 Attack Phase 해결 순서 로직이 없음.

| # | 질문 | 답변 |
|---|------|------|
| C1 | **행동 순서** — Ready 누른 순서대로 1→2→3→4 순차 실행? 전원 동시 해결? | |
| C2 | **중간 사망 처리** — 1번이 공격해서 3번 사망 → 3번이 이미 선택한 아이템은 실행? 취소? (1v1은 즉시 라운드 종료) | |
| C3 | **동일 타겟 복수 공격** — A, B 둘 다 C를 공격. A 공격으로 C가 0° → B 공격은 실행? 스코어는 A만 획득? | |
| C4 | **바람막이 vs 복수 공격** — 1턴에 2명이 나를 공격. 바람막이(1회용)로 둘 다 방어? 1건만? | |
| C5 | **동시 Ready 3+명** — 3명이 동시 Ready → 행동 순서 결정 기준? (온도 낮은 순 / 랜덤 / 서버 도착 순) | |

## 4. Multi-Player 연출/애니메이션 (신규 3건)

> 1v1 연출은 1st→2nd 순차 3초씩. 3~4명이면 최대 12초 → 너무 길 수 있음.

| # | 질문 | 답변 |
|---|------|------|
| S1 | **연출 방식** — A: 순차 (Ready 순서대로 3초씩, 최대 12초) / B: 전원 동시 재생 (3초) / C: 하이브리드 (공격자별 짧은 컷 1.5초) | |
| S2 | **사망 연출 타이밍** — 중간에 누가 죽으면 즉시 고스트 전환 연출? 전체 Attack Phase 끝나고 일괄 처리? | |
| S3 | **환경 변수 다인전 적용** — 다인전에서 환경 효과 동일? 잼민이 스틸 전원 1개씩? 앰뷸런스 최저 온도 1명만? 폭염경보 최저 온도 1명만 선공? | |
